3.1.0

  • Support for Foundry V14.
    As such far-reaching changes are bound to contain errors, I would ask, as always, that if you find any bugs, lost features or missing functionality, please let me know. The best way to do this is by submitting a bug report on GitHub. (https://github.com/Scepfari/SPACE1889-FVTT/issues). The link can also be found in the game settings under the ‘Report SPACE 1889 error’ button

  • As the old Token Action HUD Classic module is not V14-compatible, it is no longer supported and has been replaced by the modern Token Action HUD Core version. Unlike the Classic version, the Core version also requires a module tailored to the specific system; for SPACE, this is the Token Action HUD SPACE 1889 System.
    Manifest: https://github.com/Scepfari/token-action-hud-space1889/releases/latest/download/module.json

  • A few minor bug fixes
