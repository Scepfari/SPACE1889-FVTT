3.0.2

  • Bug fix: Windows cannot be minimised properly ([#30])

  • Bug fix: missing header (2px high) in the detached message window ([#31])

3.0.1

  • Two additions to the Actor context menu: direct access to the prototype token and the option to convert an NPC into a PC or a PC into an NPC

  • Character traits with campaign effects (talents, skills, specialisations, resources) now have an additional parameter for the campaign effect level; this specifies how many levels of the trait are covered by the effect in terms of XP costs.

  • Character Sheet UI Improvements: Filter Options

    • Weapons: Filter away all unusable weapons, i.e. those not currently equipped by the character
    • Ammunition: Filter away all types of ammunition that the character does not have on them
    • Armour: Filter away all armour that the character is not currently carrying.
    • Injuries: Filter away all injuries that have already healed
    • Extended actions: Filter away all extended actions that habe already been processed

  • New item type: ‘Shield’:

    • New melee specialisation: ‘Shields’
    • Shields only provide a defence bonus when held in the hand
    • Shields can also be used as melee weapons
    • The parry manoeuvre can also be performed with a shield

  • Bug fix: Parry does not take the off-hand's penalties into account ([#27])

  • Bug fix: Equipped weapons can be moved to storage/containers ([#28])

  • Bug fix: Display issues with talents that have a campaign effect ([#29])

3.0.0

  • Support for Foundry V13
    This has been a truly labour-intensive process that has kept me busy for over nine months, and it’s unlikely to have gone entirely smoothly. So if you spot any bugs, missing features or functionality, please let me know. The best way to do this is by submitting a bug report on GitHub. The link can also be found in the game settings under the ‘Report a SPACE 1889 bug’ button.

  • V12 and earlier versions will remain at version 2.3.6 and will no longer be supported

  • Switch to App V2

  • Integration of a native calendar, time management and monthly view (thanks to DSA developer Plushtoast for the inspiration)

  • Compendium: Migration to LevelDB and directory restructuring

  • Effects for skills and specialisations (similar to those of talents), for example to modify the level without affecting the XP cost.

  • Campaign effects for skills and specialisations, i.e. for the first level without spending XP; all subsequent upgrades are then gained either normally or via effects
